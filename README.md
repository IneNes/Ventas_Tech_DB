# RetailPro — Proyecto de Análisis de Datos

## Descripción del proyecto

RetailPro es un proyecto de análisis de datos orientado al estudio de ventas, clientes, productos y categorías. El objetivo es utilizar consultas SQL para obtener información comercial que permita comprender el comportamiento del negocio y apoyar la toma de decisiones.

## Herramientas utilizadas

- **SQL Server Management Studio (SSMS):** entorno utilizado para trabajar con las consultas SQL.
- **SQL:** lenguaje utilizado para consultar, relacionar y analizar los datos.
- **GitHub:** plataforma utilizada para almacenar y documentar los archivos del proyecto.
- **ChatGPT:** herramienta de inteligencia artificial utilizada como apoyo para revisar consultas, generar documentación y proponer interpretaciones que luego deben validarse.

## Organización del repositorio

- `Ventas_Tech_DB.sql`: archivo SQL principal del proyecto.
- `m3_base_ventas_tech.sql`: consultas y trabajo correspondiente al módulo 3.
- `m4_consultas_negocio.sql`: consultas de análisis comercial, incluyendo resumen mensual, ranking de productos, clientes recurrentes y comparación con el promedio mensual.
- `m5_consultas_joins.sql`: consultas con `INNER JOIN` entre ventas, clientes, productos y categorías, además de consultas complementarias.

## Cómo ejecutar los scripts SQL

1. Abrir SQL Server Management Studio (SSMS).
2. Conectarse al servidor de SQL Server utilizado para el proyecto.
3. Seleccionar la base de datos correspondiente.
4. Abrir el archivo `.sql` que se desea ejecutar.
5. Verificar que la base de datos seleccionada sea la correcta.
6. Ejecutar la consulta y revisar los resultados obtenidos.

La ejecución requiere que la base de datos y las tablas correspondientes estén disponibles en el entorno de trabajo.

## Análisis de negocio

El proyecto contempla consultas para analizar:

- La evolución mensual de las ventas.
- Los productos con mayor facturación y mayor cantidad de unidades vendidas.
- La recurrencia de los clientes.
- La comparación de las ventas con el promedio mensual.
- La integración de información de ventas, clientes, productos y categorías.

## Uso responsable de la inteligencia artificial

ChatGPT se utiliza como herramienta de apoyo para revisar consultas SQL, generar borradores de documentación y proponer posibles interpretaciones comerciales. Las respuestas de la IA deben contrastarse con el código y los resultados reales antes de aceptar sus recomendaciones o utilizarlas para tomar decisiones.
